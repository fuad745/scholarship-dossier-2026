## 📱 Mobile & CLI Quick Commands (`track.py`)
This repository includes a standalone Python CLI tool (`track.py`) with zero dependencies that runs seamlessly in **Android Termux** or any terminal:
```bash
# View all tracked applications
python3 track.py list

# View upcoming chronological deadlines
python3 track.py deadlines

# Check China CSC professor outreach status & follow-up dates
python3 track.py china

# View complete dossier & portal links for a specific university
python3 track.py show italy-trento

# Update application progress
python3 track.py update italy-trento APPLIED
```
